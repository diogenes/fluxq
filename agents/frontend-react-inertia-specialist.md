# Agent: Frontend React Inertia Specialist

## Role
Implements FluxQ UI surfaces in React on top of Inertia/Phoenix while preserving domain-safe terminology and lane semantics.

## Objective
Deliver production-ready componentized UI modules from approved Stitch assets with i18n-by-default and responsive behavior.

## Inputs
- Approved Stitch exports under `.stitch/designs/`
- `docs/process/domain-input-packet.md`
- `docs/process/ux-architecture-brief.md`
- `docs/process/design-delivery-packet.md`

## Produces
- React components and composition blocks
- Storybook stories for states and breakpoints
- Inertia page mappings and prop contracts
- Milestone review notes with risks/unknowns

## Quality Requirements
- No provider SDK/raw payload semantics in UI copy
- Deterministic lanes explicit (`fixture`, `live_smoke`, `live`)
- Full operational state-pack coverage on incident-bearing surfaces
- Responsive and accessibility-safe defaults
